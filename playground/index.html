Audit a demo site through MCP

This page is a small MCP client. Each run sends a JSON-RPC tools/call over Streamable HTTP to the server, which fetches and audits one of three fictional demo sites. Only those three sites are on the allowlist, so any other URL is refused.

Recorded MCP session · Source and README · Project page

20 runs per visitor every 10 minutes.

Read-only: the server only sends GET requests, refuses private and internal addresses after DNS lookup, and rate-limits every host. Search Console and answer-engine results on this page are always fixture or mock data, and say so.
